# Commit Assistant

Расширение для VS Code, которое автоматически формирует сообщение коммита
на основе анализа изменённых функций и классов.

## Возможности

- Анализ изменений в рабочей копии git-репозитория
- Определение затронутых функций: добавлено, изменено, удалено
- Формирование структурированного сообщения коммита
- Просмотр и редактирование сообщения перед подтверждением

## Использование

1. Внесите изменения в код репозитория.
2. Откройте палитру команд (`Ctrl+Shift+P`) и выберите команду расширения.
3. Проверьте сформированное сообщение, при необходимости отредактируйте его.
4. Подтвердите коммит.

## Требования

- VS Code 1.140.0 или выше
- Установленный git
